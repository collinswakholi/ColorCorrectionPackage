┌─────────────────────────────────────────────────────────────────────────────┐
│                           EXAMPLE USAGE FLOW                                 │
└─────────────────────────────────────────────────────────────────────────────┘

Step 1: Train Models
────────────────────────────────────────────────────────────────────────────
    from ColorCorrectionPipeline.ccp import ColorCorrection
    from ColorCorrectionPipeline.Configs.configs import Config
    
    cc = ColorCorrection()
    config = Config(do_ffc=True, do_gc=True, do_wb=True, do_cc=True)
    
    cc.run(
        Image="training_with_colorchecker.jpg",
        White_Image="white_background.jpg",
        config=config
    )

Step 2: Apply to New Image (File Path)
────────────────────────────────────────────────────────────────────────────
    results = cc.predict_image(Image="test_image.jpg", show=False)
    
    # Extract stages
    ffc_image = results['FFC']   # After flat-field correction
    gc_image  = results['GC']    # After gamma correction
    wb_image  = results['WB']    # After white balance
    cc_image  = results['CC']    # Final result (or None)

Step 3: Apply to New Image (NumPy Array)
────────────────────────────────────────────────────────────────────────────
    import cv2
    from ColorCorrectionPipeline.key_functions import to_float64
    
    img_bgr = cv2.imread("test_image.jpg")
    img_rgb = to_float64(img_bgr[:, :, ::-1])  # BGR→RGB, [0,255]→[0,1]
    
    results = cc.predict_image(Image=img_rgb, show=False)
    
    # Access final result
    final_image = results['CC']

Step 4: Save Output
────────────────────────────────────────────────────────────────────────────
    if results['CC'] is not None:
        # Convert RGB float64 [0,1] → BGR uint8 [0,255]
        output_bgr = (results['CC'][:, :, ::-1] * 255).astype('uint8')
        cv2.imwrite("corrected_output.jpg", output_bgr)

┌─────────────────────────────────────────────────────────────────────────────┐
│                          KEY CHARACTERISTICS                                 │
└─────────────────────────────────────────────────────────────────────────────┘

✓ Sequential Processing    Each stage builds on the previous
✓ Model-Based             Applies pre-trained correction models
✓ No Chart Required       Works on any image (after training)
✓ Intermediate Access     Returns results from each stage
✓ Automatic Clipping      Ensures valid [0,1] range
✓ Flexible Input          File path OR numpy array
✓ Type Safety             Strong type annotations
✓ GPU Accelerated         Uses CUDA if available (for GC)
✓ Logging Enabled         Reports timing information
✓ Error Tolerant          Continues if visualization fails

⚠ Prerequisites:
  • Models must be trained first (using run() method)
  • Reference illuminant must be set
  • Input must be RGB format (not BGR)
  • Input values must be in [0,1] range (if array)
